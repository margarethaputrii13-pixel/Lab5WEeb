Tujuan Praktikum
Praktikum ini bertujuan memahami dasar JavaScript dan interaksinya
dengan HTML melalui output halaman dan Console, alert() dan
prompt(), function, operasi aritmetika, percabangan, perulangan,
manipulasi DOM, event listener, validasi form, serta penggunaan tombol
untuk mengubah tampilan halaman.

🛠️ Teknologi yang Digunakan

HTML

CSS (jika digunakan)

JavaScript

Visual Studio Code

Browser

▶️ Cara Menjalankan

Clone atau download repository ini.

Buka folder proyek di Visual Studio Code.

Buka file HTML yang ingin dijalankan.

Jalankan file menggunakan browser atau ekstensi Live Server.

Buka Developer Tools dengan menekan F12 untuk melihat hasil pada Console.
